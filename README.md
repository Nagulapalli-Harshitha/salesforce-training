# Day 3 Salesforce Assignment

## 📌 Overview

This repository contains my **Day 3 Salesforce Assignment**, completed as part of the Salesforce Developer Training Program. The assignment focuses on Salesforce automation using **Validation Rules**, **Record-Triggered Flows**, and **Apex Triggers** within a **Placement Management System**.

---

## 📚 Contents

### Part 1 – Interview Warm-up

This section covers the following Salesforce concepts:

* Validation Rules
* Flows
* Apex Triggers
* Flow vs. Trigger
* Record-Triggered Flow
* Salesforce Order of Execution

---

### Part 2 – Placement Management System

Implemented automation in a Placement Management System to understand how Salesforce declarative tools can streamline and improve the recruitment process.

---

### Part 3 – Design Challenge

| Requirement                       | Solution              |
| --------------------------------- | --------------------- |
| Reject duplicate applications     | Validation Rule       |
| Auto-fill Application Date        | Record-Triggered Flow |
| Send email notification           | Record-Triggered Flow |
| Reject applications with low CGPA | Validation Rule       |
| Create Offer Letter record        | Record-Triggered Flow |

---

### Part 4 – Hands-on Assignment

Implemented the following Flow components:

* Start Element
* Assignment Element
* Send Email Action
* Successful Flow Execution

---

### Part 5 – Validation Rule Challenge

Created Validation Rules to ensure data quality:

* Student CGPA must meet the Job's minimum CGPA.
* Application Date cannot be later than the Job Closing Date.
* Mandatory fields cannot be left blank.

Screenshots demonstrating the validation rules and successful execution are included in this repository.

---

### Part 6 – Trigger vs. Flow Analysis

Analyzed the most suitable automation tool for different business requirements, including:

* Automatic field updates
* Creating related records
* Sending email notifications
* Calling external REST APIs
* Complex calculations
* Processing bulk records

---

### Part 7 – Mini Project Enhancement

Enhanced the Placement Management System by implementing:

* Record-Triggered Flow to automatically populate the Application Date
* Validation Rules to maintain data quality
* Automatic email notifications after application submission
* Automatic Offer Letter record creation when the Application Status changes to **Selected**

---

### Part 8 – Debugging Challenge

Explored common Salesforce automation challenges, including:

* Automation conflicts
* Recursive execution
* Governor limit issues
* Best practices for designing scalable automation
